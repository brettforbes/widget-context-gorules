# Governance rules

Shared VibeGov behavior is canonical in `@spiderfeet/.governance/rules/gov-*.mdc`. This repository does not fork those rules during W0.

Local project behavior lives in:

- `AGENTS.md`
- `.governance/project/PROJECT_INTENT.md`
- `.governance/project/GIT_WORKFLOW.md`
- `.governance/project/ISSUE_PICKUP_FLOW.md`

When a local instruction conflicts with SPEC-020, SPEC-020 wins.
