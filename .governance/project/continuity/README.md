# Continuity

| Layer | Path | Purpose |
|-------|------|---------|
| Session | `session/` | Thread-specific notes |
| Recent | `recent/` | Decisions and open loops |
| Project | `project/CONTINUITY.md` | Durable project context |

Checkpoint when requirements, blockers, or the active issue phase change. Promote a recent note into project continuity only when it remains true across issues.
